    3. Cómo organizar los archivos

    Si todavía no instalaste R y RStudio, hacelo primero: R y después RStudio Desktop, en ese orden.

    1. Descomprimí el proyecto en un lugar fácil de encontrar, por ejemplo Documentos. Clic derecho sobre el ZIP → Extraer todo. Te queda una carpeta seminario.
    2. Abrí el proyecto con doble clic en seminario.Rproj. RStudio se abre ya ubicado en la carpeta correcta.
    3. Corré la puesta a punto: abrí 00_setup.R desde la pestaña Files y apretá Source. La primera vez tarda unos minutos porque instala los paquetes.
    4. Para cada clase, descargá su ZIP y descomprimilo dentro de seminario/clases. Debería quedarte esta estructura de carpetas: 
    seminario/
├── seminario.Rproj      ← siempre abrir desde acá
├── 00_setup.R           ← se corre una sola vez
├── bases_eph/
├── Resultados/
└── clases/
    └── 01_intro_r/      ← lo que trae cada ZIP de clase
    Si R no encuentra las bases: casi siempre es porque el ZIP no se descomprimió o porque el script se abrió sin abrir antes seminario.Rproj. Nunca hace falta usar setwd().
